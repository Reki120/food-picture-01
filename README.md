# food-picture-01 entry

A steaming bowl of ramen, photographed close-up: golden glistening broth,
a swirl of noodles, a jammy soft egg, chashu pork, scallions and nori, with
steam rising. The image was generated with an AI image model from a text
prompt (no hands, no people, no text in the picture), then centre-cropped to
square and resized to 1024x1024.

`main.py` is a stdlib-only program that copies `entry.png` to the output
directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`). No network, no model
calls, deterministic.
